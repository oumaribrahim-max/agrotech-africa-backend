# 🌍 AgroTech Africa — Maquette Backend

Ce dépôt contient la maquette fonctionnelle (Mock API) du backend de la plateforme **AgroTech Africa**, une solution numérique de mise en relation directe entre les agriculteurs locaux et les acheteurs.

## 🚀 Fonctionnalités simulées
* **Gestion du catalogue** : Ajout et récupération des produits agricoles.
* **Simulation Mobile Money** : Simulation d'un paiement (Orange, MTN, Wave) avec un délai de latence réseau de 1.5s.

## 🛠️ Installation et Lancement local

Pour tester cette maquette sur votre machine :
1. Installez les dépendances : `npm install`
2. Lancez le serveur : `npm start`
3. Le serveur tourne sur `http://localhost:3000`
